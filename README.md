# Trading Dashboard

A real-time trading dashboard with Firebase integration, optimized for performance and minimal resource usage.

## Features

- Real-time data updates via Firebase
- Active and resolved signal tracking
- Advanced filtering and search
- Performance metrics and analytics
- Score-based signal evaluation
- Responsive design
- Optimized for low CPU/memory usage

## Tech Stack

- React 18.2.0
- TypeScript 5.0.0
- Vite 5.0.0
- Tailwind CSS 3.3.6
- Firebase 10.7.0
- React Query 5.8.4
- Zustand 4.4.7
- date-fns 3.0.0

## Quick Start

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deployment Commands

```bash
npm install
npm run build
railway up
```
